# IBM Plex fonts

These unmodified TrueType files are bundled for reproducible Nuggets-theme
renders; no system-wide font installation or render-time network access is needed.
`SlideBase` registers them only while constructing a scene.

Source: [IBM/plex](https://github.com/IBM/plex/tree/78cd4223d8de9fcb78cba84eadecb269c56093c5),
commit `78cd4223d8de9fcb78cba84eadecb269c56093c5`.

- Sans Regular/Bold: `packages/plex-sans/fonts/complete/ttf/`
- Mono Regular/Medium: `packages/plex-mono/fonts/complete/ttf/`
